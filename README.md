# goal-equity-advisors
Youth soccer transparency and advisory site

## Pages
- `season-cost-calculator.html`: Season Cost Calculator (the home page, `index.html`, redirects here)

## Updating prices
All calculator prices are in one block near the top of the `<script>` in
`season-cost-calculator.html`, marked **EDIT PRICES HERE** (`const COSTS = { ... }`).
Change a number and save. Nothing else in the file needs to change.

## Editing in Replit
1. In Replit, choose **Create Repl → Import from GitHub** and pick `pspieh/goal-equity-advisors`.
2. Press **Run**. The site opens in the Webview.
3. Edit, then commit and push from Replit's **Git** pane so the changes land back on GitHub.
   Pull in the Git pane before editing if anyone else has pushed changes.
